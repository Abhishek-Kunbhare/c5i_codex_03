# Cart service starter

A deliberately small checkout calculation module. `calculate_total(items)` remains the unadjusted caller contract. `calculate_total_with_coupon(items, coupon, code, now)` applies a matching coupon from `active_from` through `expires_at + 1 hour`, including the exact cutoff. All timestamps must be timezone-aware UTC datetimes. The coupon dictionary needs `code`, `active_from`, `expires_at`, and `percent` (0–100). Discounts are capped at 50 currency units; the final total is floored at zero and rounded to two decimal places, half up. An invalid percentage or timestamp raises `ValueError`. A missing coupon or code, nonmatching code, or time outside the window leaves the total unchanged. Run the dependency-free tests with `python3 -m unittest discover -s tests -v`. This starter has no production payment integration.
